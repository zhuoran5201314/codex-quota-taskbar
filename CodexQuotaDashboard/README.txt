Codex 额度仪表盘 0.1.0

适用系统：Windows 10 22H2 / Windows 11，x64
运行方式：双击“Codex额度仪表盘.exe”，程序常驻系统托盘。

操作：
- 鼠标悬浮：显示额度、重置时间、任务状态等信息。
- 鼠标右键：打开快捷菜单。
- 鼠标双击：打开设置。
- 设置中的滑块会实时预览；取消时恢复原设置，保存后写入配置。

圆环颜色：
- 75%～100%：绿色
- 50%～75%：蓝色
- 25%～50%：橙色
- 0%～25%：红色
- 无法读取：灰色

数据说明：
- 优先通过 Codex 官方 app-server 读取当前 ChatGPT 订阅额度。
- 读取额度不会调用模型，因此不会消耗 token。
- 若官方接口暂时不可用，会显示最近一次缓存，不会伪造数据。
- 本程序不会读取、复制或上传 auth.json 中的登录凭据。

便携性：
- 设置与缓存保存在程序目录下的 data 文件夹。
- 移动整个文件夹后，可在设置中重新启用开机启动以修复路径。
